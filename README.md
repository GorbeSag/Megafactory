# 🏭 Megafactory

> **بازی استراتژی-اتوماسیون دو‌نفره** با سبک Pixel Art، بدون هیچ وابستگی خارجی

## ✨ ویژگی‌های اصلی

### 🔧 سیستم اتوماسیون
- **نوار نقاله (Conveyor Belts)**: سیستم حمل‌ونقل هوشمند کالاها
- **لوله‌کشی**: انتقال آب و سیالات
- **کارگران هوشمند**: با درخت رفتاری (Behavior Tree) و سیستم Level-up
- **ماشین‌آلات خودکار**: معدن‌کاوی، کشاورزی و صنعت

### 💰 اقتصاد زنده
- **عرضه و تقاضای واقعی**: قیمت‌ها بر اساس بازار تغییر می‌کنند
- **قراردادهای تجاری**: فروش خودکار به NPCها
- **بازار پویا**: نوسان قیمت‌ها در طول روز‌های بازی

### 🔬 درخت تکنولوژی
- **تحقیق و توسعه**: فناوری‌های جدید برای ماشین‌های پیشرفته
- **سیستم ارتقاء**: بهبود کارگران، ساختمان‌ها و ابزارها
- **تغییرات بصری**: هر فناوری جدید شکل دنیا را تغییر می‌دهد

### 🛡️ دفاع و ساخت‌وساز
- **دیوارهای دفاعی**: با مقاومت متفاوت
- **تهدیدات محیطی**: حملات حیوانات و دزدان
- **استحکامات دفاعی**: برج‌های نگهبانی

### 🎨 گرافیک و بصریات
- **Pixel Art**: کاملاً دستی و بدون کتابخانه
- **سیستم ذرات پیشرفته**: جرقه، غبار، باران، برف
- **Dirty Rectangles Rendering**: بهینه‌سازی برای موبایل
- **انیمیشن‌های روان**: ۴+ فریم برای هر حالت

### 👥 گیم‌پلی دو‌نفره
- **Split-Screen**: دو دوربین مستقل
- **اتحاد یا رقابت**: بازی‌کنندگان می‌توانند همکاری یا رقابت کنند
- **لاگ رویدادها**: ثبت اتفاقات مهم
